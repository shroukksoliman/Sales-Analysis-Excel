# Mini Project Sales Dashboard

## Project Overview

This project focuses on analyzing sales data using Microsoft Excel.
The data was cleaned, analyzed, and visualized to identify key sales
and profit insights.

## Tools Used

* Microsoft Excel
* Data Cleaning
* Data Analysis
* Data Visualization
* Dashboard Creation

## Key Results

* Total Sales: 2,297,200
* Total Profit: 286,397
* Total Orders: 9,994

## Project Objectives

* Clean and organize the sales data.
* Analyze sales and profit performance.
* Identify important trends and insights.
* Create an interactive sales dashboard.
